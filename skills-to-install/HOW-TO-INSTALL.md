# How to Install These Skills Permanently

## Skills included:
- `frontend-design` — production-grade frontend UI with bold aesthetics
- `ui-ux-pro-max` — comprehensive UI/UX design intelligence (99 guidelines, 161 palettes, 57 font pairings)

## Installation Steps

1. Open File Explorer
2. Navigate to:
   ```
   C:\Users\Mushfiq\AppData\Roaming\Claude\local-agent-mode-sessions\skills-plugin\
   ```
3. Find the folder that matches your session (contains a `skills` subfolder)
4. Inside `skills\`, copy both folders:
   - `frontend-design\` (contains SKILL.md)
   - `ui-ux-pro-max\` (contains SKILL.md)
5. Restart Claude desktop app
6. Skills will appear in your available skills list
