Step 1 — Create the Database in pgAdmin 4

1
Open pgAdmin 4 and create the database
Takes about 2 minutes

Option A — Using the Query Tool (recommended)

  1. Open pgAdmin 4
  2. In the left tree, right-click PostgreSQL → Query Tool
  3. Paste the SQL below and click ▶ (Execute / F5)
-- Run this entire block in pgAdmin Query Tool:
CREATE DATABASE sams_db;
CREATE USER sams_user WITH PASSWORD 'your_database_password_here';
GRANT ALL PRIVILEGES ON DATABASE sams_db TO sams_user;

-- Connect to the new database, then run:
\c sams_db
GRANT ALL ON SCHEMA public TO sams_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public
  GRANT ALL ON TABLES TO sams_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public
  GRANT ALL ON SEQUENCES TO sams_user;
💡 The \c sams_db command only works in psql terminal. In pgAdmin Query Tool, after running the first 3 lines, change the database dropdown from postgres to sams_db, then run the last 3 lines.

Option B — GUI method

  1. Right-click Databases → Create → Database → Name: sams_db → Save
  2. Right-click Login/Group Roles → Create → Login/Group Role
    Name: sams_user | Password: your_database_password_here | Privileges: Can login ✓ → Save
  3. Right-click sams_db → Properties → Security → Add sams_user with ALL → Save
✓ When done, you should see sams_db in the Databases list in pgAdmin.

Step 2 — Configure the Backend .env File

2
Create the backend environment file
Tells the app how to connect to your database

Inside the sams-fullstack\backend folder, create a file named exactly .env (no other name, just .env). Paste this content:

PORT=5000
NODE_ENV=development

# --- Database ---
DB_HOST=localhost
DB_PORT=5432
DB_NAME=sams_db
DB_USER=sams_user
DB_PASSWORD=your_database_password_here

# --- JWT Secret (keep this private) ---
JWT_SECRET=sams_local_dev_secret_key_change_this_in_production_min64chars_2026xx
JWT_EXPIRES_IN=8h
JWT_REFRESH_EXPIRES_IN=7d

# --- Files ---
UPLOAD_DIR=./uploads
MAX_FILE_SIZE_MB=10

# --- CORS ---
CLIENT_URL=http://localhost:5173

RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX=500
⚠️ If your PostgreSQL runs on a different port (check pgAdmin → server properties), change DB_PORT. Default is 5432.

If you used a different password in Step 1, update DB_PASSWORD to match.

How to create a .env file in Windows

  1. Open the backend folder in File Explorer
  2. Right-click empty space → New → Text Document
  3. Name it .env — Windows may warn about removing the extension, click Yes
  4. Open it with Notepad and paste the content above
  5. File → Save
💡 Alternative: Open Command Prompt in the backend folder and run: copy NUL .env — then edit with Notepad.

Step 3 — Install Dependencies

3
Run 2_install_dependencies.bat
Double-click the file — takes 2–5 minutes

In the sams-fullstack folder, double-click 2_install_dependencies.bat

This runs npm install in both the backend and frontend folders.

✓ Done when you see "Dependencies installed successfully!"
❌ If it says "node is not recognized" — Node.js isn't installed or PATH wasn't set. Reinstall Node.js with "Add to PATH" checked and restart your computer.

Step 4 — Create Database Tables

4
Run 3_run_migration_and_seed.bat
Creates all 12 tables + demo accounts

Double-click 3_run_migration_and_seed.bat

✓ Done when you see the demo account credentials printed.
❌ If migration fails with "password authentication failed" — check DB_PASSWORD in backend\.env matches what you set in Step 1.
❌ If it says "connection refused" — PostgreSQL service isn't running. Open Services (Win+R → services.msc) and start postgresql-x64-16 (or your version).

Verify in pgAdmin 4

After running, refresh your sams_db in pgAdmin → Schemas → public → Tables. You should see 12 tables:

audit_log, refresh_tokens, student_addresses, student_china_experience,
student_documents, student_education, student_financial, student_language,
student_notes, student_passport, student_work_experience, students, users

Step 5 — Start the Application

5
Double-click START_SAMS.bat (every time)
Opens backend + frontend, then launches browser

Double-click START_SAMS.bat — two black windows will open and your browser will go to http://localhost:5173

⚠️ Keep both black windows open while using SAMS. Closing them stops the servers.

Troubleshooting

Starting PostgreSQL if it's not running

If you see "connection refused" errors, PostgreSQL service may have stopped.

Method 1 — Services window

  1. Press Win + R, type services.msc, press Enter
  2. Find postgresql-x64-16 (or your version)
  3. Right-click → Start

Method 2 — Command Prompt (as Administrator)

net start postgresql-x64-16
Replace 16 with your PostgreSQL version number (check what version pgAdmin shows).

Daily Use — After First Setup

Every day, just double-click START_SAMS.bat — that's it!

Make sure PostgreSQL is running first (pgAdmin 4 should be able to connect).
