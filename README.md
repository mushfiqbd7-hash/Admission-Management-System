# SAMS – Student Admission Management System

SAMS is a full-stack web application for managing international student admission applications, documents, user roles, status workflow, and export operations.

## Features

- JWT-based authentication
- Admin, Staff, and Viewer role support
- Student admission record management
- Multi-section student application form
- Document upload and management
- Individual student PDF/print export
- Bulk student export
- Dashboard with application statistics
- User management for administrators
- Staff notes for student records
- Admission status workflow
- Audit log support
- Docker deployment support
