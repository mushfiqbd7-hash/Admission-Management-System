# Contributing

1. Fork the repo
2. Create feature branch: `git checkout -b feature/your-feature`
3. Commit changes: `git commit -m "feat: description"`
4. Push: `git push origin feature/your-feature`
5. Open a Pull Request

## Commit Convention
- `feat:` new feature
- `fix:` bug fix
- `ci:` CI/CD changes
- `docs:` documentation
- `refactor:` code refactor
